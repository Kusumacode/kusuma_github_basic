Array: Arrays in jave is used to store homogeneous(same datatype) values, it will never store hetrogeneous(mixture of data) values. The syntax,
1. datatype variable[]=new datatype[size];
2. datatype []variable=new datatype[size];
e.g: int rollno[]=new int[5];
